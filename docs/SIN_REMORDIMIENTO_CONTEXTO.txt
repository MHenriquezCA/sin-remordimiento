ARQUITECTURA (decisión D1 — RESUELTA 04/10/2026)
───────────────────────────────────────────────────────────────────
Fase actual: SITIO ESTÁTICO (previo a Fase I). Sin backend.
Stack:
  Vite (instalado, no CDN) + Tailwind CSS v4 vía @tailwindcss/vite
  JavaScript vanilla (sin Alpine por ahora; entra si se justifica)
  HTML5 semántico, Mobile First, tokens de marca con @theme
Descartados:
  Tailwind por CDN → no apto para producción, fuera del estándar.
  CSS puro → obliga a reescribir al migrar a Laravel.
Razón: el proyecto escalará a panel admin con inventario (Laravel
  Fase I). Tailwind v4 + @theme se porta directo a Blade.
 
Hosting: GitHub Pages
Deploy:  GitHub Actions — push a master → npm ci → npm run build
         → publica dist/ en Pages.
         dist/ en .gitignore (el build NO se versiona; difiere de
         Sueños al Horno porque aquí el CI sí tiene Node).
Vite base: '/sin-remordimiento/' mientras se sirva desde
         mhenriquezca.github.io. Con dominio propio → base: '/'.
